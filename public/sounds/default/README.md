# Sonidos de Vienna

Basados en **Impact Sounds 1.0**, de Kenney: https://kenney.nl/assets/impact-sounds (CC0-1.0).

Movimiento: impactWood_light_000. Captura: impactWood_medium_000. Jaque: dos golpes; mate: tres. Edición: conversión a WAV mono, recorte de silencio, fundidos breves y ajuste de volumen.

Las fuentes PCM están en scripts/audio/. Se regeneran sin descargas ni dependencias adicionales con npm run sounds:generate. Procedencia y SHA-256 en provenance.json; aviso original en licenses/Kenney-Impact-Sounds.txt y licencia completa en licenses/Vienna-Sounds-CC0.txt.
